# User Stories

Reference the Writing User Stories final project guide in the course portal for more information about how to complete each of the sections below.

## Outline User Roles

1. **Foodie** — A user who loves exploring new bakeries and cafes and wants to track places they want to visit and have visited.
2. **Traveler** — A user who is visiting a new city and wants to discover and save the best-rated local bakeries to check out during their trip.
3. **Regular** — A user who frequently visits the same local bakeries and wants to keep track of their favorite items at each place.
4. **Business Owner/local cafe managers** — A business owner, I want to be able to see what other competitors, and how are they rated, and what people like about them  
5. **Local Tourism Board** — municipal or regional groups who benefit from apps driving foot traffic to local businesses and hidden gems within specific city neighborhoods.

## Draft User Stories

1. As a foodie, I want to [add a location to my bucket list], so that [I can keep track of places I want to visit].
2. As a foodie, I want to [mark a location as visited], so that [I can track places I have already been].
3. As a foodie, I want to [delete a location from my list], so that [I can remove places I am no longer interested in].
4. As a foodie, I want to [add menu items to locations], so that [I can keep track of what I want to try].
5. As a foodie, I want to [rate a menu item I have tried], so that [I can keep track of how much I like it].
6. As a traveler, I want to [view all location details on one page], so that [I quickly decide if I want to visit].
7. As a traveler, I want to [filter locations by city], so that [I can find places to visit in a specific location].
8. As a traveler, I want to [add notes to a location], so that [I remember important details like whether or not a location is cash only].
9. As a regular, I want to [take notes on menu items], so that I can [note what it pairs well with].
10. As a regular, I want to [add a pastry directly to the bakery], so that [I don’t have to navigate away from the page].
